## 🎯 Подготовка к собеседованию в Уралсибе

### Технологии, которые нужно повторить (по приоритету)

#### 1. Kubernetes (критично — основная зона развития)
**Что нужно знать на базовом уровне:**
- Архитектура: control plane (API server, etcd, scheduler, controller manager), worker nodes (kubelet, kube-proxy, container runtime)
- Основные объекты: Pod, Deployment, Service, ConfigMap, Secret, Ingress, PVC/PV
- kubectl: get, describe, logs, exec, apply, delete
- Helm: что это, как работает, chart structure, values.yaml
- Как деплоить приложение: Deployment + Service + Ingress

**Как быстро подготовиться (1-2 недели):**
- Minikube или kind локально → развернуть простое приложение
- Пройти курс "Kubernetes для начинающих" (YouTube/Stepik)
- Прочитать официальную документацию (concepts + tasks)

#### 2. Helm
- Что такое Helm chart, структура (Chart.yaml, values.yaml, templates/)
- Команды: helm install, upgrade, rollback, list, uninstall
- Как писать простой chart для приложения

#### 3. Ansible
- Playbooks, roles, inventory, modules
- Идемпотентность, handlers, templates (Jinja2)
- ansible-playbook, ansible-galaxy

#### 4. Terraform
- Основные концепции: providers, resources, variables, outputs, state
- terraform init, plan, apply, destroy
- Понимание IaC подхода

#### 5. Сети (TCP/IP L4-L7)
- OSI модель, TCP vs UDP, HTTP/HTTPS
- DNS, DHCP, NAT, балансировка (L4/L7)
- TLS/SSL, сертификаты

#### 6. Мониторинг (VictoriaMetrics, ELK)
- VictoriaMetrics — совместимость с Prometheus, отличия
- ELK: Elasticsearch, Logstash, Kibana — централизованное логирование
- Vector — сбор и маршрутизация логов
