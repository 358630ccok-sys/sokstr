HomeLab: Proxmox / Docker / RAG / Ollama

Домашняя MLOps/DevOps-лаборатория (2025 — н.в.) — спроектирована и эксплуатируется как площадка для практики инфраструктуры, автоматизации и локального ИИ.

Инфраструктура

  • Proxmox VE: кластер LXC/VM, развёртывание и сопровождение сервисов
  • Docker / Compose: контейнеризация сервисов и изоляция окружений
  • GPU: AMD ROCm + NVIDIA (базовая эксплуатация под inference/медиа)
  • Мониторинг: Prometheus/Grafana (базово), диагностика и документирование изменений

AI & автоматизация

  • Ollama: локальный inference LLM (в т.ч. coder-модели, эмбеддинги)
  • RAG: Dify + эмбеддинги + база знаний (Obsidian), поиск контекста без раздувания промпта
  • n8n: автоматизация процессов и интеграций
  • Telegram-боты: сценарии взаимодействия с сервисами/знаниями
  • ComfyUI: медиа-пайплайны (изображения/видео, эксперименты)

Схема (упрощённо)

Cloud planner
   -> Local executor (LLM/Ollama)
      -> n8n (автоматизация)
         -> Dify / RAG (Knowledge Base)
            -> Telegram-боты / сервисы
