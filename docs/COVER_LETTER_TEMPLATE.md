**1. Production-эксплуатация (Lenta, 2023 — н.в.)**
Работаю инженером техподдержки в федеральной розничной сети: диагностика и устранение инцидентов в SLA, анализ логов, эскалация, документирование решений. Это дало мне понимание production-среды, процессов изменений и взаимодействия с командами.

**2. Собственная инфраструктура (18+ сервисов)**
Спроектировал и сопровождаю кластер на Proxmox VE (LXC/VM, Docker): мониторинг (Prometheus/Grafana, дашборд ai-monitoring-2026), автоматизация (n8n, Bash/Python), CI/CD (GitLab/Runner), reverse proxy (Nginx), AI-инфраструктура (Ollama GPU inference, RAG, Dify, Qdrant, ComfyUI).

**4. AI/MLOps контур**
Развернул локальный LLM inference (Ollama, ROCm/GPU), RAG-систему (SQLite + embeddings, 309 чанков Obsidian), AI-приложения (Dify) и пайплайны генерации (ComfyUI).

## 🎯 Рекомендации по использованию

| Ситуация | Какой вариант |
|---|---|
| Быстрый отклик на HH.ru | Вариант 1 (короткий) |
| Важная вакансия / целевая компания | Вариант 2 (развернутый) |
| Прямое сообщение рекрутеру в Telegram/LinkedIn | Вариант 3 (для мессенджеров) |
| Отклик через LinkedIn Easy Apply | Вариант 1 + ссылка на GitHub |

## ⚠️ Важно
- Всегда прикрепляйте резюме (PDF или ссылка на GitHub)
- Указывайте ссылку на GitHub-портфолио
- Адаптируйте первый абзац под конкретную вакансию (название компании/должности)
- Не отправляйте одинаковый текст массово — рекрутеры замечают шаблонность
- Отвечайте на отклики в течение 24 часов
