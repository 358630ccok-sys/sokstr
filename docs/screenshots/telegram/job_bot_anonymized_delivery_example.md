# Job Hunter Bot — обезличенный пример формата доставленного отчёта

> **Важно:** это **обезличенный пример формата** (шаблон для демонстрации/документации), а не подтверждённый скриншот реальной доставки сторонним пользователям.  
> Для усиления доказательств (вакансии с вопросом «кто пользуется») приложите **реальный обезличенный** артефакт: скриншот/экспорт из Telegram-чата или лог доставки с удалёнными `chat_id`, токенами, именами, аватарами и служебными ссылками.

## Контекст запуска (пример, обезличено)
- **Дата/время запуска:** `2026-11-20 09:00 (Europe/Moscow)` *(пример)*
- **Режим:** `scheduled run` *(пример)* / `--demo` для воспроизводимой проверки формата
- **Источники:** hh.ru (API), LinkedIn (guest/RSS fallback)
- **Назначение:** общий чат/канал команды *(пример сценария развёртывания; фактический получатель не раскрывается)*

## Пример сообщения (формат, как в Telegram)

```text
Вакансии hh.ru:
- DevOps Engineer (Remote), 180 000-250 000 RUB gross, https://hh.ru/vacancy/123456
- MLOps Engineer, от 220 000 RUB net, https://hh.ru/vacancy/234567
- Site Reliability Engineer, Не указана, https://hh.ru/vacancy/345678

Вакансии LinkedIn:
- DevOps Engineer (Kubernetes), Не указана, https://www.linkedin.com/jobs/view/1111111111
- AI Infrastructure Engineer, Не указана, https://www.linkedin.com/jobs/view/2222222222
```

## Как воспроизвести формат локально (без сети/отправки)
```bash
# stdout
python3 job_bot/job_hunter.py --demo

# сохранить отчёт в файл (для артефакта/обезличивания)
python3 job_bot/job_hunter.py --demo --out docs/screenshots/telegram/job_bot_demo_YYYY-MM-DD.txt
```

## Как получить реальный обезличенный артефакт (рекомендация)
1. Выполнить реальный запуск в тестовом/рабочем чате (с разрешением участников).
2. Сохранить скриншот или экспорт сообщения.
3. Обезличить: скрыть `chat_id`, имена пользователей, токены, внутренние ссылки/идентификаторы.
4. Добавить подпись: дата, источник, количество найденных вакансий, подтверждение доставки (без секретов).
