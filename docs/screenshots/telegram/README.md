# Telegram / Bot Artifacts

- `job_bot_demo.txt` — безопасный демонстрационный вывод `job_bot/job_hunter.py --demo` (без сети, без отправки в Telegram, без реальных токенов/чат-ID).
- `job_bot_demo_2026-11-20.txt` — воспроизводимый demo-артефакт, сохранённый через `--out` (без сети/отправки, без секретов).
- `job_bot_sample_report.md` — пример структуры Telegram-отчёта (обезличенный формат).
- `job_bot_anonymized_delivery_example.md` — **обезличенный шаблон/пример формата доставленного отчёта** (не является доказательством стороннего использования без реального обезличенного скриншота/лога).

**Назначение:** показать формат отчёта, воспроизводимость и безопасный способ генерации артефактов (`--demo`, `--out`).

> Реальные рабочие отчёты/скриншоты могут содержать чувствительные идентификаторы (`chat_id`, имена, токены, ссылки) — при добавлении доказательств доставки **обязательно обезличивать** данные.
